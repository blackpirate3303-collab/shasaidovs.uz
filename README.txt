Shasaidovs — сайт для планирования меню на неделю

Структура:
- index.html      главная страница сайта
- css/style.css   оформление и адаптивный дизайн
- js/app.js       логика сайта, меню, рецепты, аккаунты и список продуктов

Запуск:
1. Распакуйте архив целиком.
2. Откройте index.html в браузере.
3. Для корректной работы оставьте папки css и js рядом с index.html.

Важно:
Это локальная демонстрационная версия. Данные хранятся в браузере на текущем устройстве;
для настоящих аккаунтов с доступом с разных устройств нужен сервер и база данных.
